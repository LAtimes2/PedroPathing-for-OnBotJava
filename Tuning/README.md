# Tuning PedroPathing for OnBotJava



This folder contains a modified version of the PedroPathing QuickStart application (QuickStart\_PP3.apk). The main modification is to parse the Constants.java file from the OnBotJava directory. This allows you to modify Constants.java without having to re-build the application.
